# Module 3 (20 min): Dashboard and Wrap-Up

## Build a basic dashboard

1. In Databricks SQL, create visualizations from:
   - revenue by product
   - daily revenue trend
   - revenue by region
2. Pin these visualizations to a new dashboard.
3. Add a short title and one-sentence business takeaway per chart.

## Student mini-assignment (5–10 min)

Answer in 3–4 bullet points:

- Which product should be prioritized and why?
- Which region appears strongest?
- What extra data would reduce uncertainty in the recommendation?

## Instructor close-out

- Recap Lakehouse + BI value proposition.
- Highlight reproducibility using Databricks Free Edition.
- Suggest next steps: larger datasets, medallion architecture, and governance.
