# 2-Hour Crash Course: Business Intelligence with the Data Lakehouse

This workshop is a ready-to-teach crash course for university students in a Business Intelligence class.

It uses **Databricks Free Edition** for reproducible, no-cost exercises:
<https://www.databricks.com/learn/free-edition>

The structure follows the spirit of the Jupyter Book workshop template:
<https://github.com/jupyter-book/workshop-template/>

## Learning goals

By the end of this crash course, students will be able to:

1. Explain the Data Lakehouse concept and where BI fits.
2. Load and inspect data in Databricks.
3. Write SQL for BI-style analysis.
4. Build a simple dashboard and communicate insights.

## Session plan (120 minutes)

- **0:00–0:10** Introduction and context
- **0:10–0:25** Databricks setup and workspace tour
- **0:25–0:55** Lakehouse basics with a reproducible sample dataset
- **0:55–1:35** BI analysis with SQL
- **1:35–1:55** Dashboard creation and interpretation
- **1:55–2:00** Recap and extension ideas
